# Робо-Арена 2D

Динамичная 2D-арена роботов в духе Quake 3: быстрый бег, двойной прыжок и прыжок от стены,
ракетные прыжки, прыжковые площадки, телепорты. Сетевая игра P2P (WebRTC через PeerJS) —
друзья подключаются, отсканировав QR-код. Можно добавлять ботов. Приложение — PWA,
работает на компьютере и телефоне. Крови нет: выбитый робот лопается конфетти.

## Возможности

- **27 видов оружия**: бластер, молот, автомат, дробовик, двустволка, ракетомёт, гранатомёт,
  плазмаган, рельсотрон, молния, супер-шар (БФГ), гвоздомёт, миниган, снайперка, морозилка,
  рикошет-лазер, мины, кассетник, самонаводка, гравитон (воронка), дискомёт, арбалет, тесла,
  пузырятор, ударная волна (отражает снаряды), зенитка, бумеранг.
- **Физика**: фиксированный шаг 60 Гц, AABB-коллизии с подшагами, «койот-тайм», буфер прыжка,
  переменная высота прыжка, отдача, отбрасывание взрывами, ящики можно толкать и ставить друг на друга.
- **Разрушаемость**: стекло, дерево, кирпич и камень (с трещинами), ящики, взрывные бочки (цепные взрывы).
- **Предметы**: аптечки, мега-здоровье, броня, патроны, оружие и 5 усилителей
  (тройной урон, ускорение, силовой щит, реактивный ранец, регенерация).
- **Боты**: навигационный граф по тайлам + A*, выбор цели и оружия, упреждение при стрельбе,
  уклонение, 5 уровней сложности. Добавлять и убирать ботов можно прямо во время матча.
- **Режимы**: каждый сам за себя и командный; 4 карты (одна — с пропастями).
- **Мобильные устройства**: два плавающих стика, кнопки прыжка и смены оружия, компактный HUD,
  полноэкранный режим и альбомная ориентация.

## Запуск

```bash
npm install
npm start          # http://localhost:4200
```

Камере (сканеру QR) нужен HTTPS или localhost. Чтобы проверить игру с телефона в локальной сети,
запустите `npm run start:lan` (dev-сервер с самоподписанным HTTPS на 0.0.0.0).

## Деплой на GitHub Pages одной командой

```bash
npm run deploy
```

Команда собирает проект с `--base-href ./` и публикует `dist/p2p-game/browser` в ветку `gh-pages`
через пакет `gh-pages` (так же, как в проекте p2p). Нужен настроенный `origin` на GitHub,
а в настройках репозитория — Pages → Deploy from branch → `gh-pages`.
Маршруты hash-based (`#/join/<код>`), поэтому `404.html` не нужен.

## Как играть по сети

1. «Создать комнату» → выберите настройки → появится QR-код и код комнаты.
2. Друзья сканируют QR-код камерой телефона (откроется ссылка) или в игре: «Подключиться».
3. «В бой!». Можно заходить и во время матча; QR-код есть в меню ☰.

Устройство создателя комнаты — хост: на нём идёт авторитетная симуляция и работают боты.
Клиенты отправляют ввод и предсказывают своё движение (с пересимуляцией по подтверждённому вводу),
а остальных видят с экстраполяцией. Снапшоты идут по неупорядоченному каналу, события — по надёжному.

Сигнальный сервер PeerJS и STUN/TURN — те же, что в проекте p2p (`src/environments`).

## Игра без интернета

Режим «📶 Без интернета»: устройства в одной сети Wi-Fi (или на точке доступа телефона хоста)
подключаются друг к другу напрямую, обмениваясь двумя QR-кодами. Хост показывает приглашение,
игрок сканирует его и показывает ответ, хост сканирует ответ. Сервер не нужен, игроков можно
добавлять и во время матча.

Пошаговая инструкция и решение проблем — в [docs/OFFLINE.md](docs/OFFLINE.md).

## Управление

| | Клавиатура/мышь | Телефон |
|---|---|---|
| Бег | A / D | левый стик |
| Прыжок | W / Пробел / ПКМ | левый стик вверх; ослабить и снова вверх — двойной (запасная кнопка ⤒) |
| Спрыгнуть с платформы | S | левый стик вниз |
| Прицел / огонь | мышь / ЛКМ | правый стик; за внутренним кольцом — огонь, прицел мягко подтягивается к врагу |
| Оружие | колесо, Q / E, 1–0 | ◀ ▶ вверху справа |
| Таблица / меню | Tab / Esc | ☰ |

На телефоне стики работают только у левого и правого краёв экрана (касание в центре
игнорируется), а камера держит робота выше центра — пальцы его не закрывают. Меню
вертикальное; при входе в игру экран поворачивается горизонтально (на Android — сам,
на iOS — подсказка повернуть телефон), при выходе меню снова вертикальное.
При попадании по вам и при выбивании соперника телефон коротко вибрирует.

## Структура

- `src/app/game/` — движок без Angular: `world.ts` (симуляция, оружие, урон), `physics.ts`,
  `tiles.ts`, `maps.ts`, `weapons.ts`, `bot.ts` + `nav.ts`, `net.ts` (протокол и клиентское
  предсказание), `renderer.ts`, `effects.ts`, `input.ts`, `engine.ts` (цикл и сеть).
- `src/app/services/` — `peerjs.service.ts` (на основе сервиса из p2p, много игроков),
  `lan.service.ts` (офлайн-режим: WebRTC с обменом QR-кодами), `transport.ts` (общий интерфейс),
  `audio.service.ts` (звуки интерфейса из p2p), `sfx.service.ts` (процедурные звуки WebAudio),
  `pwa.service.ts`.
- `src/app/pages/` — меню, создание комнаты, подключение (сканер QR), игра.

## Тесты

```bash
npm test
```

Проверяются: число видов оружия, корректность карт, симуляция матча ботов на всех картах,
кодирование ввода и сходимость клиентского предсказания с хостом.

Иконки PWA пересоздаются командой `npm run icons`.
